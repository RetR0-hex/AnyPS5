# Repository instructions

## Comments in changed code

- When changing code, add or update comments in every code file you touch.
- Comments should explain intent, assumptions, invariants, API or hardware behavior, and synchronization or data-layout requirements where relevant.
- Keep comments close to the behavior they describe. Do not add comments that only paraphrase the code.
- If the existing code and surrounding comments already explain the relevant behavior accurately, revise or extend those comments rather than adding redundant prose.

## Git attribution

- Use the configured human Git identity as the sole commit author and committer.
- Do not include Claude, Codex, Anthropic, OpenAI, or any other AI as an author or co-author.
- Do not add AI co-author trailers.
